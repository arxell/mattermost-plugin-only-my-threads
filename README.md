# Only My Threads

Плагин для Mattermost, который добавляет кнопку в заголовок канала. По клику справа открывается панель «Мои треды» со списком **только тех тредов текущего канала, первое сообщение в которых написали вы**.

Основан на официальном [mattermost-plugin-starter-template](https://github.com/mattermost/mattermost-plugin-starter-template).

## Что делает

- Кнопка 💬 «Мои треды» в заголовке каждого канала (в новых версиях Mattermost плагинные кнопки собраны в меню «…» рядом с названием канала).
- Клик открывает/закрывает правую панель (RHS) со списком ваших тредов в текущем канале:
  - корневое сообщение (короткий текст без разметки),
  - число ответов,
  - дата последней активности,
  - сортировка от самых свежих по активности.
- Клик по треду открывает его в интерфейсе Mattermost.
- Список автоматически обновляется при новых сообщениях в канале (по websocket-событию `posted`) и по кнопке «⟳».
- Клик по треду открывает его **в боковой панели с полем ответа** («Ответить в этой теме…»), как в Saved Messages: можно сразу написать, Enter — отправить. Работает и для тредов, и для «ожидающих ответа» сообщений; тред предзагружается, поэтому панель появляется мгновенно.
- Кнопка **↗** в строке («Показать в канале») выполняет переход к посту в канале: хост прокручивает ленту к сообщению и подсвечивает его (штатная permalink-механика Mattermost).
- Пагинация по месяцам: панель грузит только текущий месяц (`from:вы in:канал after:… before:…` — фильтрация на стороне сервера), старые месяцы подгружаются кнопкой «Показать ещё: {месяц}» по одному; пустые месяцы пропускаются автоматически (до 12 подряд). Счётчики ответов и даты добираются точечными запросами тредов.
- Сообщения **без ответов** показываются с пометкой «⏳ Ожидает ответа» (цель панели: видеть, где вы ждёте ответа); как только приходит ответ, item превращается в обычный тред с числом ответов. Нужен включённый на сервере поиск (по умолчанию включён); без него срабатывает fallback — разовое чтение потока канала (окно 1000 постов) без пагинации по месяцам.
- Локализация: русский и английский. Язык берётся из настроек аккаунта (Settings → Display → Language); панель и подпись иконки подхватывают его, заголовок панели/тултип обновляются при следующей загрузке страницы. Словари — в `webapp/src/i18n/messages.ts`; любой другой язык откатывается на английский.
- Работает в веб-версии и в десктоп-приложении.

## Установка

Готовый артефакт: `dist/only-my-threads-0.7.0.tar.gz`.

1. Админ сервера включает загрузку плагинов: **System Console → Plugins → Plugin Management → Enable Plugin Uploads** (если ещё выключено) и включает **Enable Plugins**.
2. **System Console → Plugins → Plugin Management → Upload Plugin** → выбрать `dist/only-my-threads-0.7.0.tar.gz`.
3. В списке плагинов найти **Only My Threads** и нажать **Enable**.
4. Обновить страницу клиента Mattermost (Ctrl/Cmd+R).

Серверной части у плагина нет (только webapp), токены и настройки не нужны — клиентская часть ходит в API от вашей сессии.

## Сборка из исходников

Нужны Node.js (18+) и Go (для сборочных утилит шаблона).

```bash
make dist        # соберёт webapp и упакует dist/only-my-threads-<версия>.tar.gz
```

Полезные команды в `webapp/`:

```bash
npm ci           # установить зависимости
npm run lint     # ESLint
npx tsc          # проверка типов
npm run build    # только webapp-бандл (webapp/dist/main.js)
npm test         # юнит-тесты
```

## Как устроено

- `webapp/src/index.tsx` — регистрация расширений: кнопка в заголовке канала (`registerChannelHeaderButtonAction`), панель RHS (`registerRightHandSidebarComponent`), редьюсер и websocket-обработчик `posted` для автообновления.
- `webapp/src/components/rhs.tsx` — панель «Мои треды»: загрузка, состояния, список.
- `webapp/src/utils/threads.ts` — месячная пагинация через серверный поиск (`Client4.searchPosts` с `from/in/after/before`), точечные запросы `Client4.getUserThread` для счётчиков и fallback-скан потока канала.

## Ограничения

- Ограничений на глубину истории нет: сколько месяцев назад вы писали — туда и можно пролистать.
- Треды «без ответов» не показываются (это не треды). Показать и их — легко, см. подсчёт `replyCount` в `utils/threads.ts`.
- Переход в тред выполняется обычной навигацией по permalink (`/{team}/pl/{post_id}`), то есть с перезагрузкой страницы.
- Панель показывает треды канала, в котором вы находитесь; переключение канала обновляет список автоматически.
